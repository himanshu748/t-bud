# T-Bud landing page fidelity ledger

The supplied Relay screen is treated as product-design evidence, not a page to copy. T-Bud keeps its dense decision language and visible consent state while adapting the composition to a public landing page.

| Comparison point | Relay evidence | T-Bud translation | Review result |
| --- | --- | --- | --- |
| Product identity | Condensed black wordmark and headline | Condensed T-Bud mark, oversized headline and square signal | Preserved with a distinct orange human-control signal |
| Agent intent | Natural-language request anchors the main workspace | The four-friend Manali request anchors the handshake | Preserved with the approved demo constraints |
| Human approval | Cart and changes require explicit review | A2A pulse stops at an itinerary approval gate | Strengthened as the hero's primary interaction idea |
| Decision evidence | Budget, product fit and audit evidence stay visible | Quote total, catalog origin, capacity check and policy result stay visible | Preserved without imitating the shopping layout |
| Interface density | Fine rules divide operational regions | Instrument panels, protocol runway and ruled value sequence | Preserved while allowing landing-page breathing room |
| Accent system | Blue marks machine evidence, yellow marks review | Blue marks protocol, orange marks human action and green marks valid state | Re-authored for clearer semantic ownership |
| Commercial story | Recommended products build a bounded cart | Base ₹16,000, rejected ₹20,800 and approved ₹19,600 show a bounded upsell | Adapted to trekking services and the user's budget |
| Failure recovery | Proposed changes remain reviewable | Budget conflict and last-seat sellout return to human review | Extended for the booking-specific demo |

## Copy differences

- Relay: “Tell Relay what the day looks like.”
- T-Bud: “Make every adventure bookable by an agent, without losing human control.”
- Relay: “Review & approve.”
- T-Bud: “Awaiting human approval” with separate hold and payment consent in the product flow.
- Relay uses a retail cart. T-Bud uses a versioned trek quote, seat hold and Razorpay test checkout.
